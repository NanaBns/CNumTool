【汉字数字 → 阿拉伯数字 转换器】使用说明
==================================================

这是什么？
  把一个文件夹里所有文本文件中的汉字数字，批量换成阿拉伯数字。

    第一章 总则      →  第1章 总则
    十二、           →  12、
    （三）           →  （3）
    一百零五         →  105
    第十二集.txt     →  第12集.txt      （文件名也能一起改）

--------------------------------------------------
怎么用（推荐）
--------------------------------------------------
  1. 把整个「汉字数字转换工具」文件夹，复制到你要处理的文件夹里
     （或者放在哪儿都行，处理时再选文件夹也可以）；
  2. 双击【双击启动.bat】；
  3. 窗口里的文件夹路径已经填好，先点【预览会改什么】看看效果；
  4. 确认没问题，点【开始转换】。

  · 转换前程序会自动把原文件备份成「_汉字数字转换备份_时间」文件夹；
  · 改错了？在同一个窗口点【撤销上次转换】，文件和文件名全部还原。

--------------------------------------------------
「智能」和「全部」有什么区别？
--------------------------------------------------
  智能（推荐）：只改有把握的数字。
      会改：第一章、十二、、（三）、一百零五、第三单元、共十二章
      不改：一样、一直、一个人、十二生肖、十分、万一、千万

  全部：连“一样”也会变成“1样”，只有确认文件里全是编号时才用。

--------------------------------------------------
改哪些文件？
--------------------------------------------------
  · 默认只改文档类：txt、md、csv、srt、log、json、html 等；
  · 想连带改代码文件（.py/.js/.css…），把“处理范围”换成“文档 + 代码文件”；
  · 图片、压缩包、exe、视频等二进制文件会自动跳过，不会损坏；
  · Word（.docx）、Excel（.xlsx）暂时不支持——需要的话跟我说，我可以加上。

--------------------------------------------------
不想开窗口，想双击一下就转完？
--------------------------------------------------
  双击【一键转换（不弹界面）.bat】，它会直接处理这个文件夹，
  处理完显示改了什么，然后按任意键关闭。

--------------------------------------------------
注意事项
--------------------------------------------------
  · 重要文件请先「预览」，确认没有把不该改的词改掉；
  · 「_汉字数字转换备份_…」文件夹千万别手动删，删了就没法撤销；
  · 如果双击 .bat 提示找不到 Python：装一个 Python 3（python.org），
    安装时勾选 “Add python.exe to PATH”。

--------------------------------------------------
常见问题
--------------------------------------------------
  · 双击 .bat 一闪而过 / 没反应
      说明没找到 Python 3。装好后重新双击即可。
      （也可以在命令行里运行 .bat，能看到具体错误。）

  · 文件变成乱码
      本程序会自动识别 UTF-8、带 BOM 的 UTF-8、GBK 编码，并按原编码写回。
      万一还是乱码：先点【撤销上次转换】，再把那个文件发给我看看。

  · 预览显示“没有发现需要修改的内容”
      可能文件类型不在范围内（换“处理范围”），或者数字写得比较隐晦
      （比如“十二生肖”这种，智能模式故意不改）。

--------------------------------------------------
命令行走法（给喜欢折腾的人）
--------------------------------------------------
  python 汉字数字转换.py --convert "D:\某个文件夹"
        可选参数：
          --all        用“全部”模式（更激进）
          --any-file   什么后缀的文件都按文本处理
          --sub        包含子文件夹
          --no-rename  只改内容，不改文件名
          --no-content 只改文件名，不改内容
          --quiet      少打印一些
